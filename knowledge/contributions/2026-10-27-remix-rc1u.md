# Acon Digital Remix

**Category:** stem-separator · **Style:** modern · **Vendor:** Acon Digital · **Preference:** 80/100  
**Matches FX:** `VST3: Acon Digital Remix (Acon Digital) (2->12ch) (Stem Splitter)`, `Acon Digital Remix`  
**Replaces:** none (no stock REAPER equivalent)

## What it does

Real-time AI stem separation as an insert. Splits a stereo mix into five stems (Vocals, Piano, Bass, Drums, Other) and lets you rebalance, solo or mute them live, e.g. turn vocals up in a reference, make a karaoke version, or duck the music bed under dialogue in post. With every control at default the stems sum back to the original. Besides the main mix output it has a separate output per stem, so each stem can be routed to its own REAPER track and processed with its own inserts. Light on CPU, but has a fixed latency of 11,264 samples (about 0.25 s at 44.1 kHz), so it's for mixing/editing, not live use. Separation is good but not artifact-free: mid-range instruments and diffuse spill are the hardest; in reviews "Other" mostly ends up as guitars/synths, and it sounds less natural than offline tools like RipX.

## Key parameters by name

| Parameter | Range | Description |
|-----------|-------|-------------|
| Vocals / Piano / Bass / Drums / Other Gain | -48 to +12 dB (default 0 dB) | Level of each stem in the mix output only |
| Mute <stem> | Off / On | Removes the stem from the mix output |
| Solo <stem> | Off / On | Auditions the stem(s) in the mix output |
| <stem> Sensitivity | -100 to +100 % (default 0 %) | How readily audio is assigned to this stem. Positive = more natural but more spill; negative = less spill but more artifacts |
| Program | Reset, Karaoke, Separate bass, Separate drums, Separate piano, Separate vocals | Factory program selector (loading one overwrites all mixer params) |

Outputs: Mix + Vocals, Piano, Bass, Drums, Other (12 channels = 6 stereo pairs). **The individual stem outputs ignore Gain, Solo and Mute; only Sensitivity changes them** (manual, "Individual Stem Outputs").

## Recommended settings

### Rebalancing a stereo mix/reference (single output)

| Parameter | Value | Why |
|-----------|-------|-----|
| All Sensitivity | 0 % | Manual: start where the network works as trained, adjust only if needed |
| Target stem Gain | ±3 to ±6 dB | Small moves hide artifacts; large boosts expose spill/warble |
| Other stems | 0 dB | Sum stays identical to the source |

### Karaoke / remove vocals

| Parameter | Value | Why |
|-----------|-------|-----|
| Program | Karaoke (or Mute Vocals On) | Mutes the vocal stem |
| Vocals Sensitivity | +20 to +50 % (inferred) | Pulls more vocal residue into the muted stem, at the cost of some instrument spill being removed too |

### Isolating one stem (e.g. pull out bass or drums)

| Parameter | Value | Why |
|-----------|-------|-----|
| Program | Separate <stem> (solos it) | Fast audition |
| That stem's Sensitivity | negative (-20 to -50 %) for cleaner isolation (inferred) | Less spill, more artifacts |

### Music under dialogue (post)

Duck Vocals Gain -6 to -12 dB on the music bed so dialogue sits on top while instruments stay (vendor blog use case).

### Stems to separate tracks in REAPER (multi-out)

1. Set the source track to 12 channels (`set_track_info` channel count 12) so REAPER keeps outputs 3-12.
2. Create one track per stem; `add_send` from the source to each, source channels = that stem's pair, destination 1/2.
3. Turn off the source track's master/parent send (or mute its Mix output path) so the mix isn't doubled.
4. Delay: all outputs share the same plugin latency; REAPER's PDC compensates.

Expected pair mapping (vendor output order; not verified live): 1/2 Mix, 3/4 Vocals, 5/6 Piano, 7/8 Bass, 9/10 Drums, 11/12 Other. Check the pin names in the FX window's "2 in 12 out" pin connector before relying on it.

## Presets worth knowing

Factory programs: **Reset** (all neutral), **Karaoke** (mutes Vocals), **Separate bass / drums / piano / vocals** (solos that stem). `set_fx_preset` loads them by name.

## When to prefer this

**The user's go-to stem separator, for every separation job** (user's own choice): real-time rebalancing of a reference or finished stereo mix, karaoke/backing tracks, sampling, dialogue-vs-music in post, *and* pulling stems for export or further processing (use the multi-out routing above, or render the soloed stems). Don't reach for an offline separator (RipX, iZotope RX Music Rebalance, Demucs) unless the user asks. Only caveat: the 0.25 s latency rules it out for live monitoring. Its sibling Remix:Drums splits a drum stem further (kick, snare, toms, cymbals) with per-stem pan.

## Learned notes

**Param indices (VST3, 25 params):** 0 Vocals Gain · 1 Piano Gain · 2 Bass Gain · 3 Drums Gain · 4 Other Gain · 5 Mute Vocals · 6 Mute Piano · 7 Mute Bass · 8 Mute Drums · 9 Mute Other · 10 Solo Vocals · 11 Solo Piano · 12 Solo Bass · 13 Solo Drums · 14 Solo Other · 15 Vocals Sensitivity · 16 Piano Sensitivity · 17 Bass Sensitivity · 18 Drums Sensitivity · 19 Other Sensitivity · 20 Bypass (plugin's own) · 21 Program · 22 Bypass (REAPER) · 23 Wet (REAPER) · 24 Delta (REAPER)

**Normalized (0–1) scaling, verified by probing:**

- Gain: linear in dB, dB = -48 + 60 × v; v = (dB + 48) / 60 (0 → -48.0 dB, 0.25 → -33.0, 0.5 → -18.0, 0.75 → -3.0, 0.8 → 0.0 default, 1 → +12.0). Floor is -48 dB, not -inf; use Mute for silence.
- Sensitivity: linear, % = -100 + 200 × v (0 → -100 %, 0.25 → -50 %, 0.5 → 0 % default, 0.75 → +50 %, 1 → +100 %).
- Mute / Solo: toggles, On when v > 0.5 (0.49 → Off, 0.51 → On).
- Program: 6 steps at v = k/5: 0 Reset · 0.2 Karaoke · 0.4 Separate bass · 0.6 Separate drums · 0.8 Separate piano · 1.0 Separate vocals.

**Gotchas:**

- Setting Program (param 21) loads that program immediately and overwrites all gains, mutes, solos and sensitivities. Never batch it with other param writes; set it first or use `set_fx_preset`.
- Program between steps is unreliable: v = 0.5 displayed "Separate bass" but loaded Separate drums (Solo Drums On). Use exact k/5 values.
- After writing Program, REAPER's reported preset name (`get_track_properties` → `preset`) can stay stale; read params 10–14 / 5–9 to know what is actually soloed/muted.
- Stem outputs (3–12) ignore Gain/Solo/Mute; on the multi-out path only Sensitivity matters. Do the balancing on the receiving tracks.
- A new REAPER track has 2 channels; outputs 3–12 are dropped until the track is set to 12 channels.
- Fixed 11,264-sample latency (web sources); REAPER PDC handles it on playback, but it's unusable for live monitoring.
